`PROTOCOL` 常量。判据结构、判决表、归类与计账规则在任何审计结果被查看之前
写定；v1.1 只调整了**复跑单位与 n 的记法**（把"每轮位复跑 n_A 次"改为

判级语义不改：三值判决（PASS / FAIL / INCONCLUSIVE）与既有分母口径完全沿用，

## 1. 动机：为什么这不是给 L1_P37 打的补丁

差分 oracle 的一条 witness 是这样一个断言：

> 在轮位 r（策略、sub_index、seed 三元组确定的一个具体输入）上，
> 变异体的输出与参考路径的输出超出容差，**因此**该变异体非等价。

这个断言隐含一个前提：**同一轮位上，未变异的原内核与参考路径是一致的**。
如果原内核在 r 上自身就不确定（竞态、非确定归约顺序、原子加浮点累加顺序、
库内核的 non-deterministic algorithm 选择），那么观测到的差异不可归因于变异，
witness 不成立。

这个前提在 GPU 内核语料上系统性地不牢靠，理由与任何具体内核无关：

1. **竞态在 GPU 内核语料中普遍存在。** 跨 block 归约、分块范数、
   split-K 累加、原子写回都要求 grid 级同步；单次 kernel launch 内没有
   grid barrier，实现者常以"第二个 kernel"或 cooperative groups 解决，
   遗漏即成竞态。这类缺陷不影响均匀随机输入下的通过率（贡献落在容差内），
   因而能长期潜伏。
2. **压力策略正好放大它。** 我们的 stress 维度刻意构造重尾、稀疏极值、
   边界元素等分布；在这些分布下少数巨值主导结果，一次陈旧读就能把
   结果挪出容差。**压力测试越有效，越容易把内核自身的不确定性
   误读成变异的效果。** 这是本方法的内生风险，不是偶发事故。
3. **单轮判决没有冗余。** 生产判级在观测到第一次发散时即返回，
   witness 是 n=1 的观测。对一个翻车率 p 的轮位，单轮 witness 中
   有 p 的比例是假的，而我们无法从记录本身分辨。

因此需要的不是"给某个内核的某个策略加 skip"，而是一个**对所有 witness
一致适用**的确认协议。逐内核加 skip 的做法会招致审稿人最直接的攻击
（"你为每个内核调口径"），并且治标不治本：同一内核换个策略仍会翻车。

**反例存在性证据（本次实测，见 §7）**：`L1_P37` 原内核在
`sparse_extreme` 轮位上的翻车率为 3/39 = 7.7%，发散分布在原内核与
两个不同变异体上，与变异无关。

## 2. 协议 WC-1

### 2.1 适用范围

所有 witness，不分阶段、不分内核、不分故障类：

- E1 CSE 阶段的全部 `FALSIFIED` 记录；
- E1 equiv 阶段的全部 `WITNESSED_NON_EQUIVALENT` 记录。

唯一的例外是**非数值 witness**（无发散轮位的记录，例如已签认的
`L1_P95__relop_replace__5` SPEC_VIOLATION）：它不依赖差分 oracle 的
数值比较，不在本协议辖内，单列说明。

### 2.2 轮位保真

`scripts/_mutant_worker.py` 的 stress 轮位种子为
`seed = base_seed + equiv_runs + sub_index`，每轮开头重新
`_seed_all(seed)`，模型构造用 `_seed_all(base_seed)`。
n 次复跑通过在 `stress_policies` 列表里**重复策略名**得到——worker 的循环是
`for policy_name in stress_policies: for si in range(stress_repeats)`，
重复的策略名即重复同一组 `(policy, sub_index, seed)`。

关于 `base_seed`：把 `base_seed` 移到 stress 起始种子并令 `equiv_runs = 0`
可以省掉昂贵的随机轮前缀，但只有当模型构造不消耗 RNG 时才逐比特等价。
这一点**逐内核实测验证**而不是推断：`_wc28_probe.py` 在
`base_seed ∈ {10000, 10020, 50000, 50040}` 下分别构造原模型与变异模型，
逐一比对全部 parameter/buffer。结论：

- 29 个承载 witness 的内核中 **21 个（全部 L1）构造与种子无关**
  （多数无参数；`L1_P35` 的 GroupNorm 权重是常数 1/0），可用捷径；
- **8 个 L2 内核**（Linear/Conv 随机初始化）构造依赖种子，
  **一律回退到完整生产前缀**（`base_seed` 与 `equiv_runs` 取生产值）。
  这 8 个内核恰好都很便宜（0.29–4.1 s/轮），代价可忽略。

捷径只在**被证明逐比特等价**处使用，这是一次有效性检验，
不是逐内核调参。

### 2.3 复跑单位：(内核, 策略)

内核级不确定性是**输入分布**的性质，不是某一个种子的性质。
L1_P37 的实证正是如此：它在 `sparse_extreme / seed 50040`（sub_index 0）
上翻车，而被质疑的 witness 落在 `sparse_extreme / seed 50042`
（sub_index 2）。按"单一 seed"定义对照会漏掉真正出问题的那一轮。

因此判据 (a) 的单位是 `(内核 K, 阶段, 策略 π)`，每次复跑覆盖该策略在生产中的
**整个 sub_index 范围**（equiv：`stress_repeats = 2`；CSE 反证：3，
两者都用观测直方图核验过：equiv sub_index ∈ {0,1} 共 5,524 轮，
CSE ∈ {0,1,2} 共 27,943 轮）。于是一个单位累计
`N_c = n_A × stress_repeats` 个对照轮。

### 2.4 两条独立判据

对每条 witness `w = (探针 P, 内核 K, 策略 π, 轮位 r)`：

**判据 (a) 对照 / 内核确定性（第一阶段）。**
把**未变异的原内核**当作 candidate、与参考路径配对，在 `(K, π)` 上
复跑 `n_A = 10` 次、即 `N_c = 20`（equiv）/ `30`（CSE）个对照轮，
全部必须在生产容差内通过。

**判据 (b) 候选 / witness 复现。**
把探针 P 在**其自身的轮位 r** 上独立复跑 `n_B = 20` 次，记第一次复现发散的
复跑序号为 `j`（未复现记 `j = ∞`）。

两条判据都**恰好对应一次 worker 调用**，因为 `_equiv_mode` 在第一次
发散轮即返回：
"n_A 次全过" ≡ "对照调用跑完了全部计划轮"；
"n_B 次中第 j 次复现" ≡ "候选调用在第 j 次复跑上带 divergence 退出"。
这不是为省钱做的近似，而是判据与生产判级器语义的天然对齐。

### 2.5 判决表（分级，预先定义，不依赖结果）

| 条件 | witness 判决 | 说明 |
|---|---|---|
| (a) 第一阶段出现 ≥1 次发散 | **NON-DISCRIMINATING（该策略对该内核无判别力）** | `(K, π)` 上的**全部** witness 一律作废，与候选行为无关 |
| (a) 通过 且 `j = 1` | **CONFIRMED** | 确定性复现（见 §3.2 的论证：确定性复现本身就排除了竞态解释） |
| (a) 通过 且 `2 ≤ j ≤ n_B` | **ESCALATED**（进入 §2.6） | 间歇复现，需要率比较 |
| (a) 通过 且 `j = ∞` | **ESCALATED**（进入 §2.6） | 20 次不复现，对照的洁净度成为唯一支撑，必须加深 |

### 2.6 升级判据（ESCALATED 进入；对照加深 + 率比较）

第二阶段：对照臂在 `(K, π)` 上加深到 `N_c' = 200` 个对照轮
（0 次发散为通过；任一发散 → 回落 NON-DISCRIMINATING）。候选臂累计到
100 次复跑或 5 次发散（多次 worker 调用累加，每次调用在其首次发散处
退出，复跑数按实际执行轮累加）。以单侧 Fisher 精确检验比较两臂发散率，
显著性水平 **α = 0.01**：

- 候选 ≥5/100 且对照 0/200（p = 0.0038 < 0.01）→ **CONFIRMED-INTERMITTENT**；
- 否则 → **UNCONFIRMED**。

分级的作用是把 GPU 花在真正有疑问的 witness 上：确定性复现（`j = 1`）
的 witness 只需第一阶段对照，而"不复现"或"间歇复现"的 witness——
即对照洁净度真正承重的那些——才付 200 轮对照的代价。

### 2.6 witness 作废后的探针落级（预先定义）

作废一条 witness **不等于**把探针判成 STILL / LIKELY_EQUIVALENT。
规则是：**把该发散轮从证据里剔除（记为不可判定轮，既不计 valid_round，
也不计 kill），然后对剩余证据套用未经修改的既有判级函数。**

1. 剩余有效轮数满足既有门槛
   （CSE：`CSE_MIN_VALID_ROUNDS=77` 且 `CSE_MIN_RANDOM_PASS=30`
   且 `CSE_MIN_STRESS_ROUNDS=42`；equiv：`EQUIV_MIN_STRESS_ROUNDS=8`）
   → 按既有函数落级为 `STILL_LIKELY_EQUIVALENT` / `LIKELY_EQUIVALENT`。
   **注意**：生产运行在发散处即中止，故剩余轮数就是该记录的
   `valid_rounds`，不需要重跑即可判定门槛是否已满足。
2. 不满足门槛 → 按既定"补跑到出级"流程重跑该探针（完整生产协议，
   不加任何 policy-skip）。重跑若再次在**同一 NON-DISCRIMINATING 轮位**
   发散，该轮继续记为不可判定轮，如此累计仍无法凑够门槛
   → 落入第 3 条。
3. **KERNEL-UNDECIDABLE**：探针的判级无法在预算内完成，原因是
   通往门槛的必经轮位上未变异内核自身不确定。

### 2.7 KERNEL-UNDECIDABLE 的语义与计账

这**不是**一个新的第四值。判级语义不改：它是既有 `INCONCLUSIVE`
的一个**具名子类**，写入现有字段
`inconclusive_class = "kernel_nondeterminism"`。

计账规则：

- **不算 FALSIFIED / WITNESSED**：没有可归因的非等价证据。
- **不算 STILL / LIKELY_EQUIVALENT**：把它算成"未被证伪"会把
  内核自身的缺陷洗成变异体的清白，是对读者的误导；而且这些探针
  的等价性确实未知。
- **留在分母里**：CSE 的 453、equiv 的 527 不变。三值纪律要求
  不可判定轮进分母、永不进检出，本类同此。
- **Table 10**：计入 `INCONCLUSIVE` 列，脚注注明其中
  `kernel_nondeterminism` 若干条，并给出承载内核清单。
  `Witnessed non-eq., survived` 列相应减少，
  `Detection rate (witnessed)` 的分子分母同步。
- **§5.5 反证句**（"Counterexample search additionally falsified …
  for ? of 453 probes"）：分子用确认后的 FALSIFIED 实算数，
  另起一句报告被审计作废的条数与原因。

## 3. n_A、n_B、k 的选取论证

### 3.1 判据 (a)：为什么 3 遍不够

设轮位翻车率为 p，对照 n 轮全过（即漏判该内核为"确定性"）的概率为
`(1-p)^n`。以本次 L1_P37 实测 **p = 3/39 = 7.7%** 代入：

| 对照轮数 n | p=7.7% | p=5% | p=3% | p=1% |
|---:|---:|---:|---:|---:|
| **3** | **0.7865** | 0.8574 | 0.9127 | 0.9703 |
| 9 | 0.4866 | 0.6302 | 0.7602 | 0.9135 |
| 20 | 0.2017 | 0.3585 | 0.5438 | 0.8179 |
| 30 | 0.0906 | 0.2146 | 0.4010 | 0.7397 |
| **50** | **0.0183** | 0.0769 | 0.2181 | 0.6050 |
| 100 | 0.0003 | 0.0059 | 0.0476 | 0.3660 |

**"3 遍对照全过"的假阴性率在 7.7% 翻车率下是 78.6%。** 也就是说，
即使一个内核每 13 轮就翻一次车，3 遍对照有近八成概率报"干净"。
2026-07-30 那次 P37 复核实际执行的是 3 rep × 3 round = **9 个对照轮**，
漏判概率 48.7% —— 它抓到问题有相当的运气成分，不能作为协议依据。

第一阶段取 `n_A = 10` 次复跑 × 生产 `stress_repeats`，即
**`N_c` = 20（equiv）/ 30（CSE）个对照轮**：p=7.7% 时漏判
20.2% / 9.1%。这明显强于 3 遍（78.6%），但对 p ≲ 3% 的稀疏竞态仍有限；
残差由 §2.6 的分级规则兜底——真正靠对照洁净度承重的 witness 会被加深到
`N_c' = 200` 轮（p=7.7% 时漏判 1.4×10⁻⁷，p=1% 时 0.134）。

### 3.2 判据 (b)：为什么 k=1 且必须分级

一个反直觉但关键的事实：**k 不能取大。**

设变异**本身**引入了竞态（`sync_remove` 是我们的算子之一，
equiv 侧 F-SYNC 就有 16 条 witness）。这时原内核确定、变异体间歇发散，
这是**真的**非等价（确定性程序与非确定性程序在语义上不同）。若把
"n 次中复现 ≥k 次"当硬门槛，就会把这类真缺陷成批作废：

| 变异体真实复现率 q | P(20 次 0 复现) | P(20 次 <2 复现) | P(5 次 <2 复现) |
|---:|---:|---:|---:|
| 0.03 | 0.5438 | 0.8802 | 0.9915 |
| 0.077 | 0.2014 | 0.5374 | 0.9493 |
| 0.15 | 0.0388 | 0.1756 | 0.8352 |

k=2/n=5 会把 q=7.7% 的真间歇缺陷作废掉 95%。因此取 **k = 1**。

k=1 的代价是假确认率上升——除非分级。若把任意 `j ≤ n_B` 都直接按
CONFIRMED 计，`N_c=20, n_B=20, k=1` 的假确认率（对 p 取最坏）高达 25%。
分级之后，**不经升级即 CONFIRMED 的只有 `j = 1`**，其概率是
`(1-p)^{N_c} · p`：

| `N_c` | 最坏假确认率 | 取到最坏的 p | p=7.7% 时 |
|---:|---:|---:|---:|
| **20（equiv 第一阶段）** | **0.0180** | 0.048 | 0.0155 |
| **30（CSE 第一阶段）** | **0.0121** | 0.032 | 0.0070 |
| 200（升级后） | 0.0018 | 0.005 | 1.4e-07 |

**分级规则把"直接确认"的最坏假确认率压到 1.8%（equiv）/ 1.2%（CSE）。**

为什么 `j = 1` 可以走捷径，除了上表还有一个机制性理由：
若发散源自内核竞态，则**变异体也是竞态的**（同一份代码加一处改动），
其发散只能是间歇的；在同一输入上**第一次复跑就确定性复现**，
与"竞态解释"不相容。反之，真正的确定性 witness（同一输入、
确定性变异体）在 `j = 1` 的概率按构造为 1，所以这条捷径对真 witness
零损失。

落入 `j ≥ 2` 或 `j = ∞` 的才做加深与率比较（§2.6）：
Fisher 单侧检验，对照 0/200 vs 候选 f/100，f=5 时 p=0.0038 < 0.01。
这条通道保证真的间歇性竞态变异体仍能被确认，只是要付更多 GPU。

### 3.3 随机轮位的复跑单位

生产 harness 对随机轮按 `seed = base_seed + i` 分配**互不相同**的种子，
同一随机轮位无法在一次调用内重复。协议对随机轮位的 n_A = 50 定义为：
**从产生该 witness 轮的同一输入生成器独立抽取 50 次**（其中第 i 轮
即 witness 轮本身）。这在统计上比重复同一个输入更强（它抽样的是输入
分布而非单点），代价是不再是"同一输入的逐比特复跑"；协议如实标注这一
差别。判据 (b) 对随机轮位退化为"重放生产前缀一次"，因为该轮的种子唯一。

## 4. 内核级审计：用 O(内核) 成本拿 O(探针) 结论

关键观察：**判据 (a) 是 `(内核, 轮位)` 的性质，不是探针的性质。**
共享同一 `(K, r)` 的多条 witness 共用一次对照。更进一步，同一内核的
多个轮位可以并进**一次** worker 调用（`stress_policies` 传策略并集、
`stress_repeats` 取最大 sub_index+1），因为每轮开头都重新播种，
轮与轮之间没有状态耦合。

于是：

- 判据 (a)：83 条 witness → 29 个内核 → **40 个对照单元**
  （37 个 stress 打包单元 + 3 个随机轮位单元），共 4,570 个对照轮。
- 判据 (b)：**82 个候选单元**（83 条 witness 减去 1 条非数值 witness），
  共 3,390 个候选轮。

对照单元若判"原内核自身发散"，该内核上落在该轮位的全部 witness
一次性作废；若判"稳定通过"，则该轮位上的发散不可能来自内核不确定性，
witness 进入判据 (b)。这就是用 O(内核) 的对照成本换 O(探针) 的结论。

## 5. 成本

实测标定（2026-07-30，A800，串行，与 B9 互斥）：

- 每次 worker 调用固定开销 ≈ 70 s（两次 `load_inline` 编译进
  `TemporaryDirectory`，生产语义如此，不改）；
- 每轮执行开销 = 生产实测中位数，本批 29 个内核在 31 ms（L1_P18）
  到 3.6 s（L2_P56）之间，多数 < 0.7 s；
- 参照点：2026-07-30 的 P37 复核 9 次 worker 调用耗时 775.7 s ≈ 13 min。

据此，WC-1 全量：对照 40 单元 ≈ 49 min，候选 82 单元 ≈ 58 min，
合计约 1.8–2.7 GPU-hour（候选单元多数在 `j=1` 处提前退出，实际偏下限）。
若判据 (a) 对随机轮位也坚持"逐次调用复跑 50 遍"，同一结论要花
约 5.3 GPU-hour，其中 2.9 h 只服务 83 条 witness 中的 6 条——这正是
§3.3 采用分布抽样定义的成本理由。

## 6. 与既有纪律的衔接

## 7. 触发本协议的实测证据（L1_P37）

见同目录 `E1_L1_P37竞态缺陷_语料真实缺陷发现.md`。摘要：

- `L1_P37` 是 Frobenius 范数归一化内核，phase 2 在同一次 kernel launch
  内读取全部分块部分和，**没有 grid 级屏障**——未变异版本本身即竞态；
- 未变异原内核在 `sparse_extreme` / seed 50040 轮位上自身发散
  （max_abs_error 0.017464，容差 atol=rtol=1e-2）；
- 该轮位上 `L1_P37__sync_remove__1` 的 FALSIFIED witness
  （max_abs_error 0.0175692）9/9 轮不复现；
- 生产中 100/100 全过的 `L1_P37__sync_remove__0` 在复核中反而发散
  （max_abs_error 0.0292042）；
- 合并生产与复核，L1_P37 上 39 个 `sparse_extreme` 轮出现 3 次发散
  （7.7%），分布在原内核与两个不同变异体上。
